# Portfolog
### Инструмент для мониторинга инвестиционного портфеля с веб-интерфейсом. Проект выполнен в рамках курсовой работы по дисциплине «Базы данных».

Система представляет собой API с минималистичным фронтендом для отслеживания активов в реальном времени. Ключевая особенность — использование гибридной архитектуры хранилищ: реляционной базы данных для структуры портфеля и базы данных временных рядов для истории котировок.

### Основной функционал
- Учет активов: Отслеживание текущего состава портфеля и его общей стоимости.
- Мультивалютность: Поддержка операций в рублях и долларах.

- Визуализация: Построение графиков изменения стоимости портфеля на основе исторических данных.

- Интеграция с рынком: Автоматическое получение актуальных цен акций через API Московской биржи (ISS MOEX).

- Безопасность: Авторизация пользователей реализована на базе JWT-токенов.

- Отказоустойчивость: Настроено автоматическое резервное копирование базы данных на удаленный сервер.

### Технологический стек
- Backend: FastAPI

- Frontend: Jinja2 Templates

- Базы данных:

  - PostgreSQL: Хранение данных пользователей, транзакций и метаданных активов.

  - InfluxDB: Хранение и обработка временных рядов (динамика котировок).

- Внешние API: MOEX ISS API.

- Аутентификация: JWT.
